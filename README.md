# BatchSnap

Batch photo compressor & format converter (100% offline, no interstitial ads) — Flutter / Android.

## Getting started

This repository contains only `lib/` and `pubspec.yaml`; there is no `android/` platform folder. Generate it once:

```bash
flutter create --platforms=android --org com.batchsnap --project-name batchsnap .
flutter pub get
```

Then raise `minSdk` to **24 or higher** in `android/app/build.gradle(.kts)` (required by `gal`), and add the
following inside `<manifest>` in `android/app/src/main/AndroidManifest.xml`. It is only needed for saving to the
gallery on Android 9 and below; no broad storage permission is used.

```xml
<uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE" android:maxSdkVersion="28"/>
```

```bash
dart run flutter_launcher_icons   # generates the Android launcher icons from assets/icon/
flutter run
```

## Structure

| Path | Role |
| :-- | :-- |
| `lib/services/compress_service.dart` | Target-size binary search + resolution downscaling, sequential processing |
| `lib/services/app_state.dart` | Pro status, conversion history, temp cache cleanup |
| `lib/services/picker.dart` | Multi-select via the system photo picker |
| `lib/screens/` | Home / Batch setup / Progress & result / Before-after compare |

## Release (prerelease APK)

`.github/workflows/release-apk.yml` builds a signed release **APK** and **AAB** (Play Store bundle) and attaches both to a GitHub **prerelease**.

- Push a tag: `git tag v0.1.0 && git push origin v0.1.0`
- Every push to any branch also builds and publishes a prerelease tagged `build-<run number>` (the branch name is in the release title).
- Or run the workflow manually from the Actions tab.

Signing uses these repository secrets (Settings > Secrets and variables > Actions):
`KEYSTORE_B64` (base64 of the `.jks`), `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`.
If `KEYSTORE_B64` is missing the build falls back to the debug key (the log shows a warning).
No debug APK is published.

## App icon

Source images live in `assets/icon/` and are generated by `python3 tools/make_icon.py` (needs Pillow). Edit the script and re-run to change the design.

## Ads (AdMob)

- Banner (home screen only) and rewarded ad (unlocks Pro features for one batch) via `google_mobile_ads`; see `lib/services/ads_service.dart`.
- Debug builds use Google's test ad units; release builds use the real IDs.
- The AdMob **app ID** must be in `AndroidManifest.xml` inside `<application>` (the CI workflow adds it automatically):

```xml
<meta-data android:name="com.google.android.gms.ads.APPLICATION_ID"
           android:value="ca-app-pub-4400173019354346~5995575350"/>
```

- Consent (UMP) runs at startup. Create a GDPR/privacy message in the AdMob console (Privacy & messaging) so the form actually appears in the EEA/UK.
- Before publishing, add `app-ads.txt` to your developer website and complete the Play Console Data safety form (advertising ID).
